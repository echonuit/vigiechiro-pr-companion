# Catégorie de qualité

Les **8 catégories** de qualité définies par la norme **ISO/IEC 25010**.

| Catégorie | Description |
|---|---|
| [Adéquation fonctionnelle](Categorie%20de%20qualite/Adequation%20fonctionnelle.md) | L'adéquation fonctionnelle permet d'évaluer si la solution présentée est conforme aux attentes implicites et explicites de l'utilisateur. |
| [Efficience des performances](Categorie%20de%20qualite/Efficience%20des%20performances.md) | L'efficience des performances évalue si le besoin en ressources de l'application est acceptable pour répondre aux contraintes fixées. |
| [Compatibilité](Categorie%20de%20qualite/Compatibilite.md) | La compatibilité est la capacité d'un logiciel à communiquer avec d'autres composants et à fonctionner correctement même si l'environnement matériel ou logiciel est partagé. |
| [Convivialité](Categorie%20de%20qualite/Convivialite.md) | La convivialité mesure le « niveau de praticité » pour l'utilisateur. Elle évalue l'efficacité et la satisfaction avec laquelle l'utilisateur réalise ses tâches à l'aide du logiciel. |
| [Fiabilité](Categorie%20de%20qualite/Fiabilite.md) | Capacité d'un logiciel à fonctionner correctement lors de fortes contraintes (fort trafic, panne matérielle, etc.) et suite à celles-ci. |
| [Sécurité](Categorie%20de%20qualite/Securite.md) | Capacité du logiciel à protéger ses informations. |
| [Maintenabilité](Categorie%20de%20qualite/Maintenabilite.md) | Facilité avec laquelle le logiciel peut être modifié et validé. |
| [Portabilité](Categorie%20de%20qualite/Portabilite.md) | Capacité de transfert du logiciel : facilité avec laquelle il peut être installé sur divers systèmes. |
